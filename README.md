## Sprint 2: Role-based dashboard navigation

- After login the app reads the user's role and opens `DashboardShell`.
- Students get Home, Discover, My Classes, Messages and Profile tabs.
- Teachers get Home, Classes, Create, Messages and Profile tabs.
- Profile data is kept in `ProfileStore` until the backend is ready.

Run the checks with `flutter analyze` and `flutter test`.
